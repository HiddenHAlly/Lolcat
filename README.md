## Cubiomes native libraries

The local `cubiomes-local.jar` includes native libraries for Linux x86-64, Windows x86-64/ARM64, and Android ARM64. The Java bindings require Java 23 or newer. Including the Android native library does not by itself make the Fabric mod compatible with Android; the runtime must also support the required Java Foreign Function & Memory API.
